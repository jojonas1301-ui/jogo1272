# Mesa Sombria

Jogo multiplayer de dedução social para 3–12 pessoas, em português. Interface em um único HTML (SVG desenhado à mão, sem assets externos) e servidor Node.js + WebSocket.

```sh
npm ci --omit=dev
npm start          # http://localhost:3000
npm test           # regras do jogo (WebSocket real)
```

Instruções completas, regras e como hospedar: **[LEIA-ME.md](LEIA-ME.md)**.
Pacote pronto para enviar a amigos: `Mesa-Sombria-completo.zip`.
